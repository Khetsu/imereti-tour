## ჯავშანი

ფორმა მარტივია: მიმართულება, თარიღი, გაჩერება, მგზავრების რაოდენობა, სახელი, ტელეფონი და გადახდის წესი.
ადგილის არჩევა საიტზე არ არის: მოთხოვნა WhatsApp-ში მოდის და ადგილებს თავად ანაწილებ.

## როგორ განაახლო საიტი (Cloudflare Pages)

საიტი: **https://imereti-tour.pages.dev** · კოდი: github.com/Khetsu/imereti-tour

1. შეცვალე ფაილი (ან ჩაანაცვლე გადმოწერილი `schedule-config.js` საქაღალდე `js/`-ში).
2. ტერმინალში, ამ საქაღალდეში: `git add .` -> `git commit -m "რა შეიცვალა"` -> `git push`.
3. Cloudflare საიტს თავისით განაახლებს დაახლოებით ერთ წუთში (dash.cloudflare.com -> Workers & Pages -> imereti-tour -> Deployments).

`wrangler.toml` და `package.json` Cloudflare-ისთვისაა (აწყობა არ სჭირდება, ფაილები მთავარ საქაღალდეშია) — არ წაშალო.
საიტის მისამართი წერია: `sitemap.xml`, `robots.txt` და ყველა `index.html`-ის თავში (og:image, canonical).

## გაითვალისწინე

- ადმინ-გვერდზე ცვლილება მხოლოდ შენს ბრაუზერში ჩანს, სანამ ფაილს არ ატვირთავ.
- `buses/`, `schedule/` და სხვა საქაღალდეებში `index.html` მთავარის ასლია. თუ
  `index.html`-ში ხელით შეცვლი ტექსტს ან ნომერს, იგივე შეცვალე ყველა ასლში.
  განრიგის და ფასების ფაილი ერთია და ყველა გვერდზე მოქმედებს.
- CSS-ში ზოგი წესი ორჯერ წერია (ძველი და ახალი): ბოლო წესი იმარჯვებს, ამიტომ
  წესების რიგი არ შეცვალო.
