```
imereti-tour/
├── index.html              მთავარი გვერდი (სტრუქტურა და ტექსტების ადგილები)
├── buses/  schedule/  parcels/  info/  faq/
│   └── index.html          ცალკე გვერდები (თითო მისამართზე)
├── css/style.css           დიზაინი: ფერები, ზომები, ანიმაციები (სექციები 1-26)
├── js/
│   ├── schedule-config.js  პარამეტრები: დღეები, დრო, ფასები, ზოლი, შეფასებები, რუკები
│   ├── seats-data.js       დაკავებული ადგილები
│   └── script.js           მთავარი პროგრამა (სექციები 1-14, ყველა კომენტარით)

```

## ყველაზე ხშირი ცვლილებები

| რა გინდა | სად შეცვალო |
|---|---|
| რეისის დღეები, დრო, გადატანა, გაუქმება | საიტზე `/#/admin` -> გადმოწერე `schedule-config.js` |
| ფასი, ვალუტა, ამანათის ფასი კილოზე | `/#/admin` -> ფასები |
| ზედა ყვითელი ზოლი ("რეისი გადაიდო") | `/#/admin` -> გაფრთხილების ზოლი |
| მგზავრის შეფასება | `/#/admin` -> შეფასებები (მხოლოდ რეალური) |
| პირობები (გაუქმება, ბარგი) | `/#/admin` -> პირობები და ინფორმაცია |
| დაკავებული ადგილები | `/#/admin` -> 2. დაკავებული ადგილები -> გადმოწერე `seats-data.js` |
| რუკის ბმული გაჩერებაზე | `/#/admin` -> რუკის ბმულები |
| ფერები | `css/style.css`, სექცია 1 |
| საიტის ტექსტი (სათაური, აღწერა) | `js/script.js`, სექცია 1 (`ka`, `ru`, `en`) |
| ტელეფონის ნომერი | `js/script.js` და `index.html` (მოძებნე `995598808022`) |

## როგორ განაახლო საიტი Netlify-ზე

1. შეცვალე ფაილი (ან ჩაანაცვლე გადმოწერილი `schedule-config.js` / `seats-data.js` საქაღალდე `js/`-ში).
2. app.netlify.com -> შენი საიტი -> **Deploys**.
3. გადაათრიე მთელი `imereti-tour` საქაღალდე გვერდის ბოლოში.

## გაითვალისწინე

- ადმინ-გვერდზე ცვლილება მხოლოდ შენს ბრაუზერში ჩანს, სანამ ფაილს არ ატვირთავ.
- `buses/`, `schedule/` და სხვა საქაღალდეებში `index.html` მთავარის ასლია. თუ
  `index.html`-ში ხელით შეცვლი ტექსტს ან ნომერს, იგივე შეცვალე ყველა ასლში.
  განრიგის, ფასებისა და ადგილების ფაილები ერთია და ყველა გვერდზე მოქმედებს.
- CSS-ში ზოგი წესი ორჯერ წერია (ძველი და ახალი): ბოლო წესი იმარჯვებს, ამიტომ
  წესების რიგი არ შეცვალო.
